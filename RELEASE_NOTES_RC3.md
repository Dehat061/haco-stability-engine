# Release Notes — v1.0-RC3

RC3 is a reproducibility-hardening release produced in response to the first external RC2 evaluation.

Changes:
- canonical cloud-sandbox protocol;
- separate offline wheelhouse path;
- removed pandas direct dependency;
- bounded direct dependency ranges + tested constraints snapshot;
- `verify-report` cryptographic integrity check;
- stricter semantic JSON Schema;
- effective dataset fingerprint;
- fuller runtime provenance;
- stronger sensitive gate using recurrence across transformations/folds;
- factory threat model;
- explicit tamper-test protocol.

Formal status remains: **TRL 4 demonstrated; TRL-5 readiness strengthened; external RC3 rerun pending.**
