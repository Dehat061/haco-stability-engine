# Publication checklist for SoftwareX

Before making this repository public:

- [ ] Final decision: patent filing first, or immediate public disclosure.
- [ ] Select and add an OSI-approved `LICENSE`.
- [ ] Review every repository file for secrets/private paths.
- [ ] Confirm tests pass from a clean environment.
- [ ] Confirm both frozen controls pass.
- [ ] Confirm `verify-report` passes on original artifacts.
- [ ] Add public support/corresponding email.
- [ ] Create immutable GitHub tag `v1.0.0-rc3`.
- [ ] Connect repository to Zenodo.
- [ ] Archive the GitHub release in Zenodo.
- [ ] Add Zenodo DOI to `CITATION.cff` and SoftwareX manuscript.
- [ ] Replace SoftwareX manuscript placeholders C2/C3/C4/C9.
- [ ] Submit to SoftwareX only after repository and archived release are publicly accessible.
